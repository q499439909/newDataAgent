# Operator Benchmarks

`datajuicer-cpu-baseline-v1.json` is generated by the admitted CPU Golden Set:

```powershell
.\.venv\Scripts\python.exe scripts\run_datajuicer_cpu_golden.py
```

The command uses the isolated Data-Juicer environment configured in
`dataagent.local.env`, disables model downloads, stores the immutable report in
`DomainVersionStore` as `operator_benchmark`, and refreshes the machine-specific
JSON report in this directory.

GPU/model operators are intentionally excluded. They require a separate CUDA
worker plus matching license, revision, checkpoint SHA256, Golden Set, and
benchmark evidence before release.
